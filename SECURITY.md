# Security Policy

Better Aiko is a static page with no server code or accounts. A security issue is still possible, for example script injection through icon metadata or the export code.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub's [private vulnerability reporting](https://github.com/Gitguy268/better-aiko/security/advisories/new). You should get a reply within a week.

Only the latest version on `main` (the live site) is supported.
